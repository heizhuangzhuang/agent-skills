# 文献翻译与客观译读技能 (Literature Translation & Editorial Guide)

将英文或中文学术/医学文献（尤其是系统综述、Meta 分析、队列研究、临床指南）精准提取、去术语化并重编为**纯公开学术论文的通俗客观整理与译读**，让非科研背景的读者看得懂数据、理解研究边界，同时严格剥离“医疗诊断与妊娠决策指导”风险。

参考成品范例：[dimascio2019_fetal_talipes_example.md](./examples/dimascio2019_fetal_talipes_example.md)

---

## 法务与平台合规红线（最高优先级，全流程强制执行）

> **总原则**：法律认定与平台审核（如微信公众号、微信小程序等）从来不看作者的主观初衷，只看文本的**客观表述**以及普通读者的**实际观感**。  
> **核心铁律**：**所有医学判断、数据与观点必须有明确主语（“该研究显示”“论文作者指出”“该队列记录”），绝不替读者做决定，绝不提供任何医疗或妊娠行动建议。**

### 1. 强制文首免责声明（不可省略）
每篇文章正文最顶部（主标题下方、正文第一段之前）**必须**固定放置以下声明：

> **声明**：本文仅为公开学术论文的数据整理与客观解读，不构成任何医疗诊断、检查或妊娠决策建议，具体诊疗请遵医嘱。

### 2. 四大绝对禁区（Hard Prohibitions）
1. **禁止承诺性/情绪安抚性标题与导语**：
   - 严禁使用“给你定心丸”“先别慌”“别自己吓自己”“放心”等具有隐性担保或安抚性质的措辞。
   - 改用客观中性表达：“数据拆解”“研究结果客观整理”“核心发现解读”。
2. **禁止临床定性结论与医疗/妊娠决策指导**：
   - 严禁出现“不能单凭 VUS 轻易放弃宝宝”“不加做也符合常规临床路径”“非常值得加做”“不需要做 MRI”“建议去挂 XX 科”等句式。
   - 必须客观转述论文中的实际统计与作者观点，并明确“具体是否需要检查及诊疗方案需由产前诊断/专科医生结合个体情况评估”。
3. **禁止单中心/小样本研究过度外推**：
   - 单中心回顾性研究或小样本队列的数据，只能表述为“该医院/该研究纳入的 N 例病例中……”，严禁外推为“行业共识”“全国通用常规临床路径”。
4. **禁止以“实用行动建议”收尾**：
   - 严禁设置“给准妈妈的 N 条实用行动建议”“行动清单”等指导就医、复查节奏或检查选择的模块。
   - 统一改为**“论文作者在讨论部分提到的 N 个临床关注点”**（纯转述作者原文讨论的关注事项）。

### 3. 高风险句式 vs 合规改写对照表（写作与自查必对）

| 高风险原句（存在“指导/定性/安抚”风险） | 合规改写（纯客观“论文解读”） |
| :--- | :--- |
| XX 医院 83 例产前追踪给你定心丸 | XX 医院 83 例产前追踪数据拆解 |
| 给准妈妈的 4 条实用行动建议 | 论文作者在讨论部分提到的 4 个临床关注点 |
| 单纯性足内翻……不加做也完全符合当前常规临床路径 | 该研究 47 例单纯性足内翻中，WES 额外检出率为 4.3%；具体是否加做需由产前诊断医生结合个体超声与家族史评估 |
| 不能单凭 VUS 轻易放弃宝宝 | 论文指出，意义未明变异（VUS）目前尚无明确致病结论，研究中单纯组 3 例 VUS 有 2 例最终活产 |
| 不建议常规做胎儿 MRI | 论文作者指出，该综述现有数据尚不足以支持常规开展胎儿 MRI，具体是否评估需遵医嘱 |

### 4. 数字零幻觉复核红线
- 所有 `n/N`、百分比、基因名称、遗传概率必须逐项对照提取的原文 `.txt` 核实，严禁估算、四舍五入失真或脑补原文未提及的数据。

### 5. 图文版权合规红线
- 正文须以自己的通俗语言重构改写，避免整段照搬英文原文直译。
- `journal_header` 与 `outcomes_chart` 两张配图**必须完全基于 HTML 模板自主重绘**，严禁直接截取或搬运原论文 PDF 中的图表原图。

### 6. 平台审核（如微信小程序）风险提示
- 涉医高频词（如“羊水穿刺”“胎儿足内翻”“全外显子测序”“引产”等）在个人或普通科技公司主体的微信小程序等强监管平台可能触发医疗健康/医疗资讯类目审核。本技能通过剥离“医疗指导”可大幅降低文本本身的法律与误导风险，但平台资质准入仍需发布方自行评估合规类目。

## 标准执行流程 (Step-by-Step Workflow)

### 1. 全文提取与期刊信息核实（严禁只读摘要）
1. **提取完整 PDF 文本与表格**：运行 [extract_pdf_text.py](./scripts/extract_pdf_text.py) 按页导出全文：
   ```bash
   python3 <skill_dir>/scripts/extract_pdf_text.py "/path/to/paper.pdf" "<scratch_dir>/paper_full.txt"
   ```
   必须通读 **Abstract、Introduction（定义与分型）、Results（正文细分数据）、Discussion（作者对偏倚/高估/低估的解释）以及文末所有 Tables / Figure Legends**。
2. **核实正式发表元数据与期刊指标**：
   - 若原 PDF 为 `Accepted Article` 或预印本（缺少卷期页码），使用 `search_web` 检索 `DOI` 或英文标题，补齐正式发表的 **Year、Volume、Issue、Pages、Publisher**。
   - 同步检索该期刊最新的 **影响因子（Impact Factor, IF）**、**JCR 分区（Q1–Q4 及所属学科）** 与 **中科院分区（大类及小类几区）**。

### 2. 明确读者画像与编辑视角（去术语化 + 客观归因）
- **编辑人设**：严谨、平实、去术语化的学术文献译读编辑——帮助非科研背景读者看懂论文结构、真实数据与研究边界，不做情绪担保，不越界给诊疗建议。
- **去科研化与术语白话化（面向非科研读者必守）**：
  - **避免科研术语轰炸**：正文中不要直接堆砌 `95% CI`、异质性 $I^2$、$p$ 值、`subluxation`、`equinus`、`tenotomy`、`plantigrade` 等未经转译的科研或解剖术语。
  - **生活化转译**：将专业操作转化为读者能理解的客观描述（例如：把 `percutaneous Achilles tenotomy` 译为“门诊局麻下进行的微创跟腱松解小切口”；把 `foot abduction brace` 译为“两只鞋底由横杆连接的专用矫形支具”），且每句转译必须忠实于论文原文并带主语归属。
  - **表格精简减负**：面向非科研读者时，表格去掉 $I^2$、$p$ 值、复杂置信区间等纯学术统计列，只保留**“研究关注的指标 / 阶段”、“论文统计数据 / 时间安排”、“论文原文说明 / 客观解读”**三类直观信息。
- **厘清适用边界**：在正文前段先用通俗语言转述论文中的分类定义（例如区分“单纯性/孤立性”“姿势性”与“复杂性/综合征性”），用 `> **研究适用范围**` 说明本文统计样本主要对应哪一类人群。

### 3. 生成两张标志性配图（自主重绘，无原 PDF 截图版权风险）
> **Artifact 路径规则**：若输出为 Antigravity Artifact 文档，所有生成的 PNG 必须直接保存在当前会话的 `<Artifact Directory Path>` 下，并使用绝对路径 `![说明](/absolute/path.png)` 引用。

1. **期刊名称 + 英文标题头图截图（必配，置于文章最顶部）**：
   - **必须还原该期刊的真实封面/官网主色调（严禁千篇一律套用默认蓝色！）**：生成前先检索确认该期刊的真实视觉品牌色（例如 *AOGS* 为经典深红、*Pediatrics* 为标志性“绿刊”深绿、*Elsevier* 为爱思唯尔橙+青绿、《中山大学学报》为中大绿等），并将对应色值填入模板的 CSS 变量（`--top-bg`、`--banner-start`、`--banner-end`、`--accent-color`、`--badge-bg`、`--badge-text`、`--link-color`）。
   - 复制 [journal_header_template.html](./resources/journal_header_template.html) 到 `<scratch_dir>/journal_header.html`，填入真实的出版商栏、**期刊英文全称（上方醒目横幅）**、文章类型标签（如 `SYSTEMATIC REVIEW`）、**论文原始英文标题（紧随期刊名下方）**、完整作者列表及卷期页码与 `DOI`。
   - 运行 [render_html_card.py](./scripts/render_html_card.py) 生成高清自动裁边截图：
     ```bash
     python3 <skill_dir>/scripts/render_html_card.py "<scratch_dir>/journal_header.html" "<output_dir>/journal_header_<slug>.png"
     ```
2. **中文核心结局可视化汇总图（推荐配图，置于核心表格上方）**：
   - 复制 [outcomes_chart_template.html](./resources/outcomes_chart_template.html) 到 `<scratch_dir>/outcomes_chart.html`，将原论文最核心的结局数据按逻辑分组制成横向条形图。图表标题严禁使用“定心丸”等承诺性词汇；底部 `footnote` 固定保留非医疗建议提示与方法学局限说明（如微创操作混入手术率、单中心/小样本偏倚等）。
   - 同样使用 [render_html_card.py](./scripts/render_html_card.py) 渲染输出 `outcomes_chart_<slug>.png`。
3. **视觉质检（必须执行）**：渲染后用 `read_file` 查看两张 PNG，确认中英文排版无乱码、无截断、留白匀称。

### 4. 原论文核心表格翻译与重构
不要原样照搬生硬的英文表格，按以下标准重制为面向非科研读者的中文 Markdown 表格：
- **主结局汇总表**（对应原论文核心结果表）：保留核心维度、`发生例数 / 总例数 (n/N)` 与比例，去掉 $I^2$、$p$ 值、复杂置信区间等纯学术统计列，并在最右侧使用 **`论文原文说明 / 客观解读`** 列，用一句带主语的客观话术转述含义（严禁在单元格内出现“不建议做 XX”“无需 XX”等医疗指令）。
- **正文中散落的重要亚组/细分数据**：将其提炼成结构化补充表（如按严重程度、器官系统、单双侧、或“近十年最新研究趋势”拆分的对照表）。
- **纳入研究概览表**（针对系统综述/Meta 分析）：将冗长的 `Table 1` 浓缩为一张紧凑的“数据来源概览表”（时间跨度、覆盖国家、样本总量、诊断孕周/阶段、检测手段），直观交代研究背景。

### 5. 以“客观问题拆解”组织正文并做好防误读解读
- **中性客观小标题**：避免生硬套用“引言—方法—结果—讨论”，改用中性客观的追问作小标题（例如：*“产前归为‘孤立性’的病例，后续随访结果如何？”*、*“单侧与双侧的统计结果有差异吗？”*、*“这篇研究里，染色体与基因检测的检出情况如何？”*、*“研究记录的出生后治疗方式占比如何？”*）。
- **统计偏倚防误读校准（核心编辑职责）**：凡遇到看似偏高的不良结局数字，必须结合原论文 `Discussion` 讲清背后的统计原因（例如：转诊中心病例集中导致的高危偏倚、门诊微创操作被笼统归入“手术”、年代较早设备分辨率低、小样本高危随访偏倚等），切忌只抛数字不讲背景，也切忌得出“因此无需检查/不用担心”的越界结论。
- **结尾临床关注点（严禁行动清单）**：正文末尾统一使用 **“论文作者在讨论部分提到的 N 个临床关注点”** 收尾，纯客观转述作者在原论文讨论中列出的临床关注事项（如动态随访的意义、个体化遗传咨询的讨论点、产后评估重点等），**严禁写成面向读者的行动建议或就医指令**。

### 6. 标准结尾：论文出处与期刊介绍（必含模块）
文章最末尾固定使用 `### 📚 论文出处与期刊介绍` 模块，包含两项内容：
1. **论文出处**：标准学术引用格式（作者列表、*英文原题*、**期刊全称**、发表年份、卷(期):起止页码、`DOI`）。
2. **期刊简介**：
   - 期刊英文全称、常见中文译名、简称、主办学会及出版商（如 Wiley / Elsevier / Springer Nature 等）。
   - **影响因子（IF）**：标明近年稳定区间或最新数值。
   - **期刊分区**：同时标明国际 **JCR 分区（Q1–Q4）** 与 **中科院分区（大类及小类几区）**。
   - **行业地位**：1～2 句话说明该刊在对应专科领域的学术定位与参考价值。

## 交付前自检清单 (Quality & Compliance Checklist)
- [ ] **文首免责声明**：标题下方、正文第一段之前是否已置顶“本文仅为公开学术论文的数据整理与客观解读，不构成任何医疗诊断、检查或妊娠决策建议，具体诊疗请遵医嘱”？
- [ ] **高风险词汇清零**：标题、导语、小标题、正文、表格与配图中，是否已彻底清除“定心丸”“先别慌”“别自己吓自己”“实用行动建议”以及替读者做决定的措辞？
- [ ] **主语归属与外推检查**：所有核心结论是否均有“该研究显示”“论文作者指出”等明确主语归属，且未将单中心/小样本数据外推为“常规临床路径”或“行业共识”？
- [ ] **数据与版权核实**：所有数字、`n/N`、基因名、期刊指标是否与原文及核实结果 100% 一致？两张配图是否为模板自绘、非原论文 PDF 截图，且头图已按真实期刊主色调渲染并经过 `read_file` 视觉检查？
- [ ] **标准结尾模块**：文末是否已改为“论文作者在讨论部分提到的 N 个临床关注点”，并完整列出论文出处、影响因子、JCR 分区与中科院分区？
